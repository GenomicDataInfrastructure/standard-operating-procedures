This directory contains **formally withdrawn** GDI Standard Operating Procedures (SOPs). These documents are retained for historical reference and auditability only.

## Requirements for archived SOPs

Every withdrawn SOP in this directory must:

1. Display a prominent **WITHDRAWN — NOT FOR OPERATIONAL USE** notice at the beginning of its Markdown file.
2. State the effective withdrawal date, reason, replacement SOP (if any), and withdrawal/approval references.
3. Retain its original SOP identifier, filename, content history, and version information.
4. Be linked from the register above.
5. Remain accessible for historical reference and not be presented as an active SOP.
